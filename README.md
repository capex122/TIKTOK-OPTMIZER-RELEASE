# TikTok Optimizer releases

Download `TikTokOptimizerSetup.exe` from the [latest release](https://github.com/capex122/TIKTOK-OPTMIZER-RELEASE/releases/latest) to install TikTok Optimizer on Windows. Updates are installed through the app's **Update** button. This repository distributes installer releases only.

The installer includes FFmpeg and FFprobe from the Gyan FFmpeg GPL v3 build. Their licence and build information are installed in the `FFmpeg` folder; the upstream FFmpeg source used by this build is [FFmpeg commit 9047fa1b08](https://github.com/FFmpeg/FFmpeg/commit/9047fa1b08).
